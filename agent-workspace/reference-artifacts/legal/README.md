# Governed Agreement Engineering Reference Artifacts

These files support the existing clause and template governance controls; they are not
a substitute for the signed legal instrument or the enterprise approved registers.

## Non-disturbance rule

A derivative LegalDocML/contract-XML, LegalRuleML, ACTUS or Accord representation
does not amend, cancel, novate or replace any agreement. In particular, distinct
agreements are not consolidated without an independently signed, effective legal
instrument. The authorised original and its amendment chain remain in the
approved document repository; this public GitHub repo stores generic schemas,
architecture, controlled examples and code only.

## Status and adoption

This new enterprise architecture profile is a GitHub design proposal, not
a production-deployed rule engine, an approved legal opinion or a change to
`REG-STD-001`. Unresolved authority, applicability, source verification,
legal and accounting mapping, XSD, ACTUS model support and controlled action
gates must be closed through MET-PDCA-001 before adoption.
